### [Evidence-Grounded RAG](https://github.com/Nithish-kumar-git/evidence-grounded-rag)

I built a supervised local prototype for asking questions about synthetic PDF and TXT documents. It includes extraction, configurable chunking, Gemini embeddings, pgvector similarity retrieval, server-verified demo sessions, owner-scoped document access, citation and exact-quote checks, and insufficient-evidence abstention. Citation checks do not prove semantic correctness.

- **Built with:** Python, FastAPI, React, PostgreSQL/pgvector, Gemini

- **Verification:** The documented offline Phase 7 candidate passed 77 backend tests and 10 frontend tests. Live Gemini and database integration were not re-verified; there is no public app deployment.

### [Faculty Workload Management System](https://github.com/Nithish-kumar-git/fwms-workload-system)

I developed a faculty workload management system with a PostgreSQL-backed data model, REST APIs, and a five-pass allocation fallback strategy that progressively relaxes constraints to improve allocation feasibility. It includes workload reporting, Excel exports, and role-based access controls. The separate recruiter demo uses synthetic data and is not the institution’s application or records.

- **Built with:** Python, FastAPI, PostgreSQL, React, TypeScript
- **Links:** [Synthetic recruiter demo UI](https://fwms-recruiter-demo.vercel.app/) · [Portfolio case study](https://nithish-portfolio-seven.vercel.app/case-study.html?project=fwms)
- **Demo status:** The UI responded with HTTP 200; the Render backend health endpoint returned a 503 loading page during this check, so full workflows were not verified.

### [Chit Fund Analytics](https://github.com/Nithish-kumar-git/chitfund-analytics)

I built an authenticated personal tracker that preserves source messages, separates expected calculations from recorded cash flow, and supports review, verification, and exports. It uses row-level security, idempotency keys, decimal-based calculations, and database integrity checks. This is not production-ready financial software.

- **Built with:** Next.js, TypeScript, Supabase Auth, PostgreSQL
